Comment ça marche ?

Comprendre l'architecture technique de StockFlow

Le Cœur en C

Le moteur de l'application est écrit en langage C. Il utilise des structures de données performantes (listes doublement chaînées) pour gérer les produits et les fournisseurs en mémoire vive.

Serveur HTTP Natif

Le programme C intègre son propre serveur web (utilisant Winsock2). Il écoute vos requêtes et sert directement les fichiers HTML, CSS et JS sans avoir besoin d'un serveur externe comme Apache ou Nginx.

API JSON & Fetch

L'interface web communique avec le serveur C via des appels API JSON. Chaque fois que vous ajoutez ou modifiez un produit, le navigateur envoie une requête fetch() au programme C qui traite la logique métier.

Interface Moderne

Bien que le backend soit en C, l'interface utilise les technologies web modernes (HTML5, CSS3, JS Vanilla) pour offrir une expérience utilisateur fluide, réactive et élégante.

Flux de Données

1
Action Utilisateur

Vous cliquez sur "Ajouter un produit" dans l'interface.

2
Requête Frontend

Le JavaScript envoie les données au serveur C via une requête POST.

3
Traitement Backend (C)

Le serveur C alloue la mémoire (malloc) et insère le produit dans la liste chaînée.

4
Réponse & Affichage

Le serveur renvoie une confirmation JSON et l'interface se met à jour instantanément.
